## Ideas clave a cubrir

- **El punto de quiebre:** por qué copiar y pegar archivos completos en el editor web de Apps Script deja de funcionar cuando la app crece (contexto largo, regresiones, miedo a tocar algo que ya sirve).
- **Paso a un flujo dev-friendly:** sacar el código a un repo local con archivos modulares (control de versiones, deploy automatizado).
- **TDD como red de seguridad:** tests sobre la lógica de negocio (totales, OCR, cálculos, reglas) para refactorizar y sumar features sin romper lo que ya usas todos los días.
- **Agente de código con reglas definidas:** instrucciones claras + especificación + tests para poder literalmente dictarle cambios y validar rápido.
- **Cierre / lección práctica:** la diferencia entre un prototipo desechable hecho con IA y una herramienta mantenible con criterio de ingeniería.
